Assessment & Evaluation Guidelines

คู่มือการใช้งานและโครงสร้างข้อมูลสำหรับ 4 ระบบการวัดและประเมินผล

เพื่อความถูกต้องแม่นยำในการคำนวณสถิติตามทฤษฎีการทดสอบดั้งเดิม (Classical Test Theory: CTT) คุณครูสามารถศึกษาตัวอย่างโครงสร้างตารางและการจัดวางข้อมูลดิบ (10 แถวตัวอย่าง) พร้อมกดดาวน์โหลดไฟล์แม่แบบตัวอย่าง (.csv) ไปใช้งานได้ทันที

ศูนย์ดาวน์โหลดไฟล์แม่แบบนำเข้าข้อมูล (Template Download Hub)

ไฟล์ตัวอย่างทุกไฟล์ถูกเข้ารหัสแบบ UTF-8 with BOM รองรับภาษาไทยสมบูรณ์แบบ สามารถเปิดด้วย Microsoft Excel ได้ทันที

1. ระบบประเมินความสอดคล้องเชิงเนื้อหา (IOC)

สำหรับผู้เชี่ยวชาญ 3–5 ท่านขึ้นไป ตรวจสอบความเที่ยงตรงเชิงเนื้อหา (Content Validity) รายข้อและภาพรวม

สูตรคำนวณ: IOC = ΣR / N
ΣR = ผลรวมคะแนนผู้เชี่ยวชาญ (-1, 0, +1), N = จำนวนผู้เชี่ยวชาญ
เกณฑ์ตัดสิน: ผ่านเกณฑ์ความสอดคล้องเมื่อ IOC ≥ 0.50
2. ระบบวิเคราะห์คุณภาพข้อสอบปรนัย (Item & Test)

สำหรับข้อสอบเลือกตอบ ให้คะแนนแบบทวิภาค (0, 1) ตัดกลุ่มสูง-ต่ำ 27% พร้อมวิเคราะห์ประสิทธิภาพตัวลวง

สูตรคำนวณ: p = (RH + RL) / 2f และ r = (RH - RL) / f
RH, RL = จำนวนคนตอบถูกในกลุ่มสูงและต่ำ, f = ขนาดกลุ่ม 27%
เกณฑ์ตัดสิน: ความยากง่าย 0.20 ≤ p ≤ 0.80 | อำนาจจำแนก r ≥ 0.20 | ความเชื่อมั่น KR-20 ≥ 0.70
3. ระบบวิเคราะห์ข้อสอบอัตนัย (Subjective Item)

สำหรับข้อสอบเขียนตอบ/แสดงวิธีทำ คะแนนรูบริกส์แบบพหุภาค (Polytomous: 0 ถึงคะแนนเต็มแต่ละข้อ)

สูตรคำนวณ: P = (ΣSH + ΣSL) / (2f × Smax) และ D = (ΣSH - ΣSL) / (f × Smax)
ΣSH, ΣSL = ผลรวมคะแนนกลุ่มสูงและต่ำ, Smax = คะแนนเต็มข้อนั้น, f = ขนาดกลุ่ม 27%
เกณฑ์ตัดสิน: ความยากง่าย 0.20 ≤ P ≤ 0.80 | อำนาจจำแนก D ≥ 0.20 | ความเชื่อมั่น Cronbach's α ≥ 0.70
4. ระบบวิเคราะห์แบบสอบถาม (Rating Scale)

สำหรับแบบสอบถามมาตราส่วนประมาณค่า (Likert Scale 1–5) วิเคราะห์ระดับความคิดเห็นและโครงสร้างมาตรวัด

สถิติหลัก: ค่าเฉลี่ย (¯X), ส่วนเบี่ยงเบนมาตรฐาน (S.D.) และอำนาจจำแนก rxy (Item-Total Correlation)
วิเคราะห์ความสอดคล้องระหว่างข้อคำถามกับคะแนนรวมทั้งฉบับ (Pearson Correlation)
เกณฑ์ตัดสิน: อำนาจจำแนก rxy ≥ 0.20 | ความเชื่อมั่น Cronbach's α ≥ 0.70

  1. เลือกเมนูระบบงาน ทางแถบซ้ายมือตามประเภทเครื่องมือที่ต้องการวิเคราะห์[cite: 26]

  3. ตรวจสอบความถูกต้อง: ดูผลการวิเคราะห์ระดับรายข้อและภาพรวมทั้งฉบับผ่านหน้าจอ Interactive Dashboard[cite: 1, 4]
  4. พิมพ์รายงาน PDF ทางการ: กดปุ่ม "พิมพ์รายงาน PDF" กรอกข้อมูลหัวเรื่องราชการ และกดบันทึกเป็นเอกสารพร้อมลงนามได้ทันที
